Junior Cloud / DevOps Portfolio

Praxisnahes Docker-/DevOps-Lab mit Betriebsfokus

Der Fokus liegt auf nachvollziehbaren Betriebsabläufen: Container werden nicht nur gestartet, sondern geprüft, beobachtet und mit realistischen Fehlerfällen getestet. Dazu gehören Backup-/Restore-Abläufe, Secret-Handling, HTTPS über einen Reverse Proxy, Monitoring, Alerting und CI/CD-Prüfungen.

GitHub Repository öffnen Dokumentation ansehen
Docker Docker Compose NGINX HTTPS/TLS Redis Prometheus Grafana Docker Scout GitHub Actions

Projektfokus

  • Containerbetrieb: Dockerfile, Compose, Web-App, Redis
  • Reverse Proxy: NGINX mit lokalem HTTPS/TLS
  • Betriebssicherheit: Healthchecks, Readiness, Restart Policy
  • Daten & Recovery: persistentes Volume, Backup, Restore-Test
  • Security: Secrets, Log Rotation, Image Scanning, Container-Härtung
  • Automation: GitHub Actions für Compose- und Image-Pipeline

Kompetenzbereiche

Was im Projekt praktisch umgesetzt wurde

Die Landingpage fasst die wichtigsten Themen zusammen. Die technische Tiefe liegt weiterhin im Repository und in den Dokumentationsdateien.

Containerbetrieb

Aufbau eines Web-/Redis-Stacks mit Dockerfile, Docker Compose, getrennten Umgebungen und schlankerem NGINX-Basis-Image.

Reverse Proxy & HTTPS

NGINX als zentraler Einstiegspunkt mit lokalem HTTPS/TLS, HTTP-Weiterleitung und dokumentierter TLS-Terminierung.

Backup, Restore & Readiness

Redis-Volume-Backup, Restore-Test, Healthchecks, Start-Abhängigkeiten und Stack-Readiness aus Betriebssicht.

Security & Secrets

Lokales Secret-Handling, Schutz durch .gitignore, no-new-privileges, Log Rotation und sichere Prüfwege.

Monitoring & Logging

Docker-Logs, Log Rotation, Prometheus Target API, Grafana, cAdvisor und Unterscheidung zwischen Docker-Health und Monitoring-Health.

CI/CD & Registry

GitHub Actions bauen und testen das Image, Docker Scout bewertet Schwachstellen, und eine lokale Registry zeigt Push-/Pull-Grundlagen.

Grafana Monitoring & Sensor Operations Lab

In diesem separaten Monitoring-Bereich wurden Prometheus, Grafana, Alerting, ein lokaler Webhook-Receiver, eine Antennen-/Sensor-Simulation und eine GeoJSON-Geomap zusammengeführt. Dabei ging es nicht nur um schöne Dashboards, sondern um sichtbare Zustandswechsel, Alarmwege und echte Verifikation im Lab.
